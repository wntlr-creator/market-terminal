# YH 마켓 터미널

지수·환율·코인 시세판, 관심종목, 캔들 차트, 미국 섹터, 실적 일정, 뉴스를 한 화면에 모은 개인용 주식 터미널입니다.
무료 데이터(Yahoo Finance, 업비트, 구글 뉴스 RSS)만 쓰고 API 키가 필요 없습니다. 시세는 실시간이 아니라 15~30분 정도 늦을 수 있어요.

## 📱 휴대폰 앱으로 쓰기 (설치형 웹앱 · PWA)

서버(`app.py`)를 무료 클라우드에 올리면 휴대폰 홈 화면에 앱처럼 설치해서 쓸 수 있어요.
- 시세판·관심종목·차트 마지막 봉은 **5초마다** 갱신 (`/api/live`, 야후 묶음 시세). 뉴스·실적은 10분마다, 대가 포트폴리오는 6시간마다
- 무료 야후 시세라 국내 주식·지수는 약 15~20분 지연, 미국 정규장·코인·환율은 거의 실시간이에요. 국내를 초 단위로 보려면 증권사 Open API가 필요해요
- Claude 데스크톱 앱에서 연 미리보기는 앱 브라우저로 10분마다 현재가를 받아 저장하고, 휴대폰 Claude 앱은 그 저장된 현재가를 보여줘요. PC 없이 휴대폰에서 바로 갱신하려면 GitHub Pages 주소(장중 10분마다) 또는 Render 주소(5초마다)로 여세요
- 국내 전 종목(코스피·코스닥)과 미국 상장 전 종목 검색, 고르면 그 자리에서 1년치 차트
- 서버에 Anthropic API 키를 넣으면 앱에서도 AI 기술적 분석이 돼요
- 서버가 잠깐 끊겨도 마지막 화면은 열려요(오프라인 캐시)

### 1단계 · GitHub에 올리기 (5분)
1. github.com 가입 → 오른쪽 위 **+** → **New repository** → 이름 `market-terminal` → **Public** → Create (무료 서버가 매일 만든 국내 전 종목 데이터를 가져가려면 공개여야 해요. 키·비밀번호는 파일에 없고 Render에만 넣어요)
2. 만들어진 저장소 화면에서 **uploading an existing file** 클릭 → 압축을 푼 `market-terminal` 폴더 **안의 파일·폴더 전부**(90개, `.github` 포함)를 끌어다 놓기 → **Commit changes**
3. **Settings → Secrets and variables → Actions → New repository secret**: 이름 `SEC_USER_AGENT`, 값 `YH Market Terminal 내이메일@example.com`
4. **Actions** 탭 → "국내 전 종목 + 대가 포트폴리오 갱신" → **Run workflow** 로 한 번 실행해 보기 (이후 매일 자동)

더 자세한 클릭 단위 설명은 함께 드린 설치 가이드 문서를 보세요.

### 2단계 · Render에 서버 만들기 (10분)
1. render.com → **Get Started** → **GitHub로 로그인**
2. **New +** → **Blueprint** → 방금 만든 저장소 선택 (`render.yaml`을 자동으로 읽어요)
3. 환경 변수 입력
   - `SEC_USER_AGENT` (필수): `YH Market Terminal 내이메일@example.com`
   - `ANTHROPIC_API_KEY` (선택): console.anthropic.com에서 발급한 키. AI 분석 1회에 대략 수십 원 정도 들어요(분석 길이에 따라 달라요).
   - `AI_ACCESS_CODE` (API 키를 넣었다면 필수): 아무 비밀번호. 앱에서 AI를 처음 쓸 때 한 번 입력해요. 안 걸면 주소를 아는 누구나 내 API 키로 AI를 쓸 수 있어요.
4. **Deploy Blueprint** → 5~10분 뒤 `https://yh-market-terminal.onrender.com` 같은 주소가 생겨요.

### 3단계 · 휴대폰에 설치
- **안드로이드(크롬)**: 주소 열기 → 오른쪽 위 ⋮ → **앱 설치** 또는 **홈 화면에 추가**
- **아이폰(사파리)**: 주소 열기 → 아래 공유 버튼 → **홈 화면에 추가**

### 알아둘 점
- Render 무료 서버는 15분 동안 아무도 안 쓰면 잠들어요. 다시 열 때 깨어나는 데 1분 정도 걸려요.
- 시세는 야후 파이낸스(비공식)를 써요. **본인 혼자 쓰는 용도**로만 쓰세요. 다른 사람에게 서비스하려면 증권사 Open API 같은 정식 데이터로 바꿔야 해요.
- 무료 서버는 저장 공간이 재시작 때 초기화돼요. 데이터는 시작할 때 다시 받아오니 문제는 없어요.
- 무료 서버(메모리 512MB)는 국내 전 종목 데이터를 직접 만들지 않고, GitHub Actions가 매일 만든 `docs/kr/` 파일을 6시간마다 받아 와요. 데이터 파일만 바뀐 커밋으로는 다시 배포하지 않게 `render.yaml`에 설정해 뒀어요.
- 내 PC에서 똑같이 쓰려면 `터미널 실행.bat`을 더블클릭하면 돼요(같은 서버가 PC에서 돌아가요).

## 화면 구성

| 영역 | 내용 |
|---|---|
| 상단 바 | 한국 시각 시계, 한국장/미국장(프리·정규·애프터) 상태, 마지막 업데이트 시각 |
| 시세 테이프 | 모든 시세가 옆으로 흐름 (마우스 올리면 멈춤) |
| 시장 시세판 | 국내 / 미국 / 아시아 / 코인 / 환율·원자재·금리 탭, 30일 추이 그래프, 코인은 업비트 원화가격과 김치프리미엄 |
| 관심종목 | 정렬(현재가·등락률·52주 위치·시총), 국내/미국 필터, ★ 즐겨찾기(브라우저에 저장) |
| 차트 | 1년 일봉 캔들 + 거래량, 20일·60일 이동평균, 1M/3M/6M/1Y 기간 전환, 52주 고저·거래량 비교 |
| 미국 섹터 ETF | 11개 섹터 1일/1개월 등락 히트맵 |
| 실적 발표 일정 | 관심종목 + 주요 대형주의 다음 실적 발표일, D-day, EPS·매출 추정치 |
| 뉴스 | 구글 뉴스(키워드별 한국어 기사) + 종목별 야후 뉴스 |

색은 한국식으로 **상승 = 빨강, 하락 = 파랑**입니다.

## 종목 검색

맨 위 검색창(키보드 `/`)에서 종목명·티커·초성으로 찾을 수 있어요. 예: `삼성전자`, `엔비`, `NVDA`, `ㅅㅅㅈㅈ`.
- **국내 전 종목(코스피·코스닥·코넥스 약 2,870개)**은 어디서든 검색되고 1년치 일봉 차트가 바로 떠요. 무료 [marcap](https://github.com/FinanceData/marcap) 데이터로 매일 자동 갱신돼요(전 거래일 종가까지).
- 관심종목·지수·코인·대가 포트폴리오 보유 종목과 해외 인기 종목 약 130개도 검색돼요.
- 차트 데이터가 있는 종목은 바로 차트로 이동하고, 기술적 분석도 할 수 있어요.
- **PC 실행 버전**에서는 데이터가 없는 종목도 고르면 그 자리에서 1년치 시세를 받아와요. 목록에 없는 종목은 티커를 그대로 입력하고 Enter (예: `035720.KS`, `RIVN`).
- 서버 버전(휴대폰 앱·PC)에서는 국내 종목도 장중 시세로 받아오고, 실패하면 일봉 묶음을 써요.
- Claude 화면과 GitHub Pages에서는 해외 종목을 즉석에서 받아올 수 없어요. 계속 볼 종목은 `config.json`의 `watchlist`에 넣으면 자동 갱신 대상이 돼요.

## 차트와 기술적 분석

- **이동평균선** 5·20·60·120일선을 버튼으로 켜고 끌 수 있어요 (설정은 브라우저에 기억돼요).
- **차트 종류**: 캔들 / 막대(OHLC) / 선 중에서 고를 수 있어요.
- **거래량**은 차트 아래 별도 칸에 상승일 빨강·하락일 파랑 막대와 20일 평균선으로 보여요. 위아래 차트는 확대·이동이 함께 움직여요.
- **기술적 분석** 버튼을 누르면:
  1. 페이지가 직접 RSI·MACD·볼린저밴드·스토캐스틱·이평선 배열·거래량을 계산하고,
  2. 헤드앤숄더, 역헤드앤숄더, 더블탑, 더블바텀, 컵앤핸들, 상승/하락/대칭 삼각형, 박스권을 자동으로 찾아 차트에 주황색 선으로 그려요.
  3. 이걸 합산해 종합 신호(매수 우위 ~ 매도 우위)와 지지·저항·손절·목표가를 보여줘요.
  4. **Claude 안에서 열었을 때는** AI 애널리스트가 이 데이터를 검증해 추세·모멘텀·거래량 해설과 조건부 매매 타이밍을 써 줘요 (본인 Claude 사용량을 써요). GitHub Pages로 열면 AI 해설 없이 1~3번만 동작해요.
- 패턴 감지는 규칙 기반이라 사람이 보는 것과 다를 수 있고, 투자 권유가 아니에요.

## 대가 포트폴리오 메뉴

상단의 **대가 포트폴리오** 탭에서 4명의 포트폴리오를 볼 수 있어요. 주소 끝에 `#buffett`, `#trump`, `#cathie`, `#goldman` 을 붙이면 바로 열립니다.

| 투자자 | 데이터 | 자동 갱신 방식 |
|---|---|---|
| 워런 버핏 | SEC 13F (Berkshire Hathaway) | 분기마다 새 13F가 올라오면 다음 날 아침 자동 반영 (보유 비중, 신규 매수, 비중 확대·축소, 전량 매도) |
| 캐시 우드 | SEC 13F (ARK) + ARK ETF 일일 보유내역 | 13F는 분기마다, ETF 매매는 **매일** (신규 편입·매수·매도·전량 매도) |
| 골드만삭스 | SEC 13F (Goldman Sachs Group) | 분기마다. 6,500개가 넘어 상위 40개만 표시 |
| 트럼프 | 정부윤리청(OGE) 278-T 거래 공시 | 새 공시가 올라오면 자동 감지해 목록에 추가. 텍스트로 된 PDF면 거래내역까지 추출, 스캔본이면 "원문 보기" 링크만 표시 |

- 갱신은 `.github/workflows/portfolios.yml` 이 매일 오전 8시 30분, 평일 오후 8시 30분(한국시간)에 실행합니다.
- 다음 13F 마감일은 분기말+45일이에요(3분기분은 2026-11-16). 대부분 마감 직전에 공시돼서, 그 주에 화면이 바뀝니다.
- 새 공시가 들어온 투자자는 카드에 **NEW** 표시가 7일간 붙어요.

### 꼭 필요한 설정 1가지 (SEC 접속용)
SEC는 연락처가 적힌 접속 정보(User-Agent)가 없으면 요청을 막습니다.
저장소 **Settings → Secrets and variables → Actions → New repository secret** 에서
- Name: `SEC_USER_AGENT`
- Value: `YH Market Terminal 본인이메일@example.com`

을 추가하세요. 이걸 안 하면 버핏·캐시 우드·골드만삭스 13F 갱신이 실패하고 이전 값이 그대로 남아요.

### 해석할 때 주의
- 13F는 분기말 기준 보유 현황이고 공시까지 최대 45일 늦어요. 지금 이 순간의 보유 현황이 아니에요.
- 13F에는 미국 상장 주식만 들어가요. 해외 주식·채권·현금·공매도는 빠져 있어요.
- 골드만삭스 13F는 고객 대행·헤지·시장조성 물량이 섞여 있어서 회사의 투자 판단으로 보기 어려워요.
- 트럼프 공시는 보유 잔고가 아니라 거래 내역이고, 금액은 구간으로만 공개돼요. 대부분 외부 운용사가 대신 매매하는 계좌예요.

## 방법 1. 내 컴퓨터에서 바로 보기 (5분)

**가장 쉬운 방법:** 파이썬을 설치한 뒤(설치할 때 "Add python.exe to PATH" 체크) 폴더 안의 `터미널 실행.bat`(맥은 `터미널 실행.command`)을 더블클릭하세요. 필요한 것을 설치하고 브라우저로 터미널을 열어 줘요. 창을 켜 두는 동안 시세는 10분마다, 포트폴리오는 6시간마다 갱신돼요.
SEC 13F를 받으려면 `터미널 실행.bat` 안의 `personal-use` 부분을 본인 이메일로 바꿔 두는 게 좋아요(SEC가 연락처 없는 요청을 막을 수 있어요).

직접 명령어로 실행하려면:

1. 파이썬 3.10 이상 설치
2. 이 폴더에서 터미널(명령 프롬프트)을 열고:
   ```
   pip install -r requirements.txt
   python serve.py
   ```
3. 브라우저가 `http://localhost:8000` 으로 자동으로 열립니다. 켜져 있는 동안 10분마다 데이터가 갱신돼요.

## 방법 2. GitHub Pages로 휴대폰에서도 보기 (추천)

텔레그램 뉴스봇처럼 GitHub Actions가 장중엔 10분마다(그 외 30분마다) 데이터를 받아 저장하고, GitHub Pages가 화면을 띄웁니다. 컴퓨터를 꺼둬도 돌아가요.

1. GitHub에서 **새 저장소(Public)** 만들기 → 이 폴더의 파일을 전부 올리기 (`.github` 폴더 포함)
2. 저장소 **Settings → Actions → General → Workflow permissions** 에서 **Read and write permissions** 선택 후 저장
3. **Actions** 탭 → `시세 데이터 갱신` → **Run workflow** 로 한 번 실행 (1~2분 후 `docs/data.json` 생성)
4. **Settings → Pages** 에서 Source를 **Deploy from a branch**, 브랜치 `main`, 폴더 `/docs` 로 저장
5. 1~2분 뒤 `https://<내아이디>.github.io/<저장소이름>/` 으로 접속 → 휴대폰 홈 화면에 추가해 두면 앱처럼 쓸 수 있어요

> 무료 GitHub Pages는 Public 저장소에서만 됩니다. 공개 저장소의 Actions 실행 시간은 무료예요.
> 갱신 주기를 바꾸려면 `.github/workflows/update.yml` 의 `*/30` 을 `0 * * * *`(1시간마다) 등으로 수정하세요.

## 종목 바꾸기

`config.json` 만 고치면 됩니다.

- `watchlist`: 관심종목. 국내는 `005930.KS`(코스피) / `035720.KQ`처럼 코스닥은 `.KQ`, 미국은 `AAPL`처럼 티커 그대로
- `board`: 시세판 탭과 항목. 코인에 `"upbit": "KRW-BTC"`를 붙이면 업비트 가격과 김프가 같이 나와요
- `earnings_extra`: 관심종목 외에 실적 일정을 보고 싶은 미국 종목
- `news_keywords`: 한국어 뉴스 검색 키워드

티커가 맞는지는 finance.yahoo.com 에서 검색해 보면 확인할 수 있어요.

## 알아둘 점

- 야후 파이낸스는 공식 API가 아니라서 가끔 일부 종목이 비어 올 수 있어요. 이때는 이전에 받은 값을 그대로 유지합니다.
- 장 상태 표시는 주말만 반영하고 공휴일은 반영하지 않아요.
- 참고용 화면이며 투자 판단의 근거로 쓰지 마세요.
